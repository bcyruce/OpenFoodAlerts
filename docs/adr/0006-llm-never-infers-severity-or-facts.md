# The LLM never infers severity and never generates facts

Severity shown on the site comes only from official fields (RASFF risk decision, FDA recall class); NVWA warnings are shown as "not graded". The LLM may only choose from a fixed list (or abstain), copy a span verbatim from the source text, or write a summary that restates the source text, and every AI output is badged as such. A wrong AI severity on a food-safety site would mislead people and undermine trust in the whole dataset, and this keeps the AI layer on the safe side of the EU AI Act's transparency rules for AI-generated text.
